# sweeper_roots.txt — registry of directory roots actually cleaned by this
# repo's cleanup sweepers (bead disk_magician-8to). Used by
# scripts/check_uncovered_roots.py to flag >=5 GiB directories (from
# existing discover/frontier data — no fresh du) that no sweeper owns.
#
# Format: tab-separated, one root per line.
#   <root_pattern>\t<owning_script>\t<note>
#
# root_pattern may use:
#   $HOME                  expanded to the live $HOME (or --home override)
#   $DARWIN_USER_TEMP_DIR  expanded to the canonicalized (realpath'd)
#                          `getconf DARWIN_USER_TEMP_DIR` value (or
#                          --darwin-tmp override); entries using this token
#                          are skipped when it cannot be resolved
#   a trailing *           glob-expanded against the live filesystem
#                          (metadata-only listing, never a du)
#
# This registry is built by reading the actual scripts, not guessed — see
# the note beside each entry for the exact source line. It is intentionally
# separate from scripts/lib/scratch_roots.sh (added by a sibling lane,
# feat/scratch-size-budget, for a different purpose — TMPDIR scratch size
# budgeting). The two should be unified into one canonical roots source
# after both land; see PR description "Known duplication" note.
#
# Coverage notes: registered ownership does not prove scheduled cleanup.
# $DARWIN_USER_TEMP_DIR is budget-covered by cleanup_tmp.sh / cleanup_pr_scratch.sh
# via scratch_roots_get_unique (guarded 15 GiB ceiling; safety/age/open/repo guards).
